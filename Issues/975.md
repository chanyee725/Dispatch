# #975 진행 중 카드에 이슈 | 문서 전환

- 카드 이름을 '진행 중'으로 바꾸고 헤더에 `이슈 N | 문서 M` 전환을 넣었어요. 선택은 localStorage에 기억해요.
- 문서 탭: 에이전트 presence 파일과 실행 중 계획 문서를 한 줄씩 보여요. 클릭하면 열려요.
- 계획 줄은 단계 진행(N/M)과 진행 막대를 보여요. 비면 '지금 쓰고 있는 문서가 없어요.'
- 아래 이슈 카드 줄에는 작은 '실행 중' 표시를 달았어요.
- PR: 본문 참고. 확인: 단위 테스트 14개 통과, tsc, npm run build, 헤드리스 라이트/다크.
