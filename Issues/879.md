# #879 E666: 세션 보드를 대시보드 형태로, 프로젝트 선택 카드와 프로젝트별 타임라인

- 제목+탭 헤더를 없애고 `home/dash` 카드 그리드로 바꿨어요. 왼쪽: 프로젝트 카드(전체·프로젝트·미분류)와 사용량, 오른쪽: 세션·작업 보드·타임라인 카드.
- 프로젝트 카드는 주소 링크(`#board&folder=`)라 고른 프로젝트가 모든 카드를 걸러요. 새 세션·⋯(브랜치 포함)·알림은 세션 카드 머리로 옮겼어요.
- 옛 주소: `#board=usage`·`#board=branches`는 카드 하나에 그 화면, `#board=timeline`은 타임라인 카드로 스크롤해서 열어요.
- 작업 보드는 카드(단계별 수, 먼저 볼 작업 5개, 전체 보기 → 시트)로 바뀌었어요.
- 세션 목록의 container query가 자기 자신을 보던 탓에 줄이 세로로 쌓이던 것도 고쳤어요.
