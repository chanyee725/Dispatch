# #954 이슈 행에서 채팅으로 제안받고 시작하기

- 변경: 팀이 없는 이슈 행을 누르면 채팅(도우미)이 열리고, 이슈 카드(번호·제목·상태·요약·GitHub에서 열기)가 고정되며, 제안 질문이 한 번 나가요.
- 도우미 답 아래 [시작하기]·[수정 요청]: 모델·관리자 선택, 시작하기는 동기 잠금으로 한 번만, 수정 요청은 입력창 포커스.
- 팀이 있는 이슈는 팀 패널(‘채팅으로 가기’ 추가). 이슈 행마다 GitHub 버튼. 사이드 시작 패널(IssueStartPanel)은 삭제.
- 확인: 관련 단위 테스트, `tsc -p web --noEmit`, `npm run build`, 헤드리스 라이트·다크 캡처(시작하기 2번 눌러도 관리자 1개, 수정 요청 → 입력창 포커스).
- 스크린샷·스크립트: `Issues/954/` (`capture.mjs`, 가짜 CLI·가짜 gh, 임시 워크스페이스).
