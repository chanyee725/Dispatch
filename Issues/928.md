# #928 타임라인을 팀 단위로

- 바뀐 것: 세션 보드 타임라인이 역할별 묶음 대신 팀(관리자 + 팀원) 단위로 보여요. 관리자 줄을 누르면 팀원이 펼쳐지고, 작업 중·기다림·멈춤인 팀만 기본으로 펼쳐요. 접힌 줄은 팀 활동을 합친 막대예요.
- 범례 줄과 상태 알약 칩을 없애고, 상태는 막대 모양(실선·점선·테두리·눈금)과 작은 점+글자로만 보여요. 색은 작업 중 강조 하나와 기다림(warn)·실패(bad)만 써요.
- 로직: `web/src/dispatch/lib/timeline.ts`(timelineTeams, mergeSpans, teamBusy)
- 확인: test/web/dispatch-timeline.test.ts 통과, tsc, npm run build, 라이트/다크 헤드리스 스크린샷
