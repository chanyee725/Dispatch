# #836 승인 대기를 대시보드에서 보여요 (알림 종만이 아니라)

- 대시보드 맨 위 승인 대기 카드: 시작을 기다리는 계획(제목·리드·대기 시간·막힌 이유)과 세션 권한 요청을 한곳에 보여요. 없으면 숨겨요.
- 시작하기는 계획 문서를 열고 계획 화면의 확인 대화상자를 띄워요. 권한 요청은 실행할 명령(가려진 입력, 길면 줄이고 눌러서 전체)을 보여 주고 허용/거절로 답해요.
- 리드 세션이 사라진 계획은 막힌 이유와 정리 버튼을 보여요. 정리는 새 POST /api/pipeline/dismiss로 대기 목록에서만 빼요(문서는 남아요).
- GET /api/pipeline/waiting에 revision, blockers, leadGone을 더했어요. 사이드바 대시보드 항목에 대기 개수를 보여요.
- 권한 요청은 session 이벤트의 pending으로 갱신하고, 대기 목록은 세션 삭제·한도·프로바이더 변화에도 다시 읽어요.
