# #1066 E723: 그룹을 오가는 flowchart를 Eraser 예시처럼 그리기
- 0단계: Eraser 예시 3개를 develop으로 다시 렌더해 원본과 나란히 비교, 차이 표를 이슈 댓글로 남김.
- 1단계(색): 그룹 `color:`를 자식 노드·중첩 그룹이 물려받음(자식 색 우선, `color: none`은 무채색). 가이드·스킬에 색 규칙.
- 2단계(띠 배치): 그룹을 오가는 흐름은 같은 폭 띠로 배치. 띠를 건너는 선은 칸을 쓰지 않아 이슈 DSL 폭 2405 → 1663px(조건 ≤ 1722).
- 사용자 결정: 색 없는 노드는 plain(`#d0d5dd`, 그림자 없음) 기본, light 그룹 테두리 `#eaecf0`. 스냅숏 갱신.
- 3단계(선 경로): 라우터 뒤에 줄기 공유(`route-trunks.ts`) — 한 변에서 갈라지는 Z선이 포트 하나·줄기 하나를 씀. 라벨은 자기 구간 중점 우선.
- 4단계(라벨): 갈래 라벨은 자기 가지 위(64px에서 줄바꿈, 화살촉 자리 확보), 짧은 선의 라벨은 선 옆. 이슈 DSL 폭 1717px.
- 5단계: cloud-architecture에도 띠 배치. 그룹 간 선이 그룹 안 선의 2배 이상이면 그룹을 같은 폭 층으로 쌓음. 노드를 지나던 대체 경로는 돌아가게 함. `wrapGroups`는 ELK 유지.
- 남은 일: 6 가이드·스킬 규칙과 예시 DSL, 7 문서 미리보기 폭. 한 방향 흐름 예시 2개는 ELK 그대로.
- 확인: `test/render/*.test.ts`+`test/dsl/*.test.ts` 270개 통과, `tsc -p shared`, `npm run build`.
