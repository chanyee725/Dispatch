# E717: 팀 스크립트·플러그인 후속

- `api.sh`: `-g`로 경로의 `[` `{`를 그대로 보내고, `--max-time`(기본 60초, `ATELIER_API_TIMEOUT`)으로 멈춘 서버를 기다리지 않아요.
- `team.sh`: 팀원 수가 `maxChildren`을 넘으면 관리자를 만들기 전에 멈춰요. 팀원 생성이 거절되면 방금 만든 관리자를 지워요.
- `relay.sh`: 다른 관리자가 살아 있으면 이전 팀의 머지 담당을 지우지 않아요. 첫 이슈를 다른 팀이 맡고 있으면 넘기지 못한 대기열을 출력해요.
- Claude 세션: PR 담당이 아니면 `gh pr create`, 머지 담당이 아니면 `gh pr merge`를 CLI가 거절해요(`--disallowedTools`). Codex·Gemini는 규칙만 있어요.
