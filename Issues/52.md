# #52 TaskBoard 카드 보존 — 서버 회귀 검사 통과
작업 보드에서 담당 관리자를 삭제한 뒤 서버를 재시작하고 카드가 남아 있는지 확인하세요.

- 진행 중 카드의 ETA와 단계 기록, 최근 완료 카드가 서버 재시작 뒤에도 유지돼요.
- 카드 오른쪽에 할당 관리자 이름이 표시돼요. 삭제된 관리자는 `관리자 확인 불가`로 표시돼요.
- ETA는 남은 시간, 자동 추정, 시간 초과, 미추정, 완료를 구분해요.
- 서버 변경 전 카드 보존 회귀 테스트 1개 실패, 변경 후 관련 카드·저장소 테스트 10개 통과.
- 기존 검증은 관련 웹 테스트 11개, shared/web 타입 검사 및 빌드 통과.
- 끝난 일은 카드 표시와 서버 보존 동작 검증이에요.
- 남은 일은 headless 검증, 서버 타입 검사 결과 확인, PR 확인이에요.
