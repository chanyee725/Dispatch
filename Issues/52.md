# #52 TaskBoard 카드 ETA 남은 시간·할당 관리자 이름 — 관련 검사 통과
작업 보드를 열고 관리자에게 할당된 진행 중 카드에서 ETA 남은 시간과 관리자 이름을 확인하세요.

- ETA는 남은 시간, 자동 추정, 시간 초과, 미추정, 완료를 구분해요.
- 카드 오른쪽에 할당 관리자 이름을 표시하고 미배정과 확인 불가를 구분해요.
- Sidebar와 SessionBoard는 별도 팀에서 담당해요.
- 검사 결과는 관련 테스트 11개, shared/web 타입 검사 및 빌드 통과예요.
- 끝난 일은 TaskBoard 카드 구현과 관련 검사예요.
- 남은 일은 headless 검증과 PR 확인이에요.
