# #52 작업 보드 카드 유지 — 회귀 검사 통과
담당 관리자를 삭제하고 서버를 재시작한 뒤 원래 프로젝트 보드와 전체 보드에서 카드가 남아 있는지 확인하세요.

- 원래 프로젝트와 전체 보드에 카드가 남고, 다른 프로젝트 보드에는 표시되지 않아요.
- 진행 중 카드의 ETA와 단계 기록, 최근 완료 카드가 유지돼요. 카드 오른쪽에 할당 관리자가 표시되고, 삭제된 관리자는 `관리자 확인 불가`로 표시돼요. ETA는 남은 시간, 자동 추정, 시간 초과, 미추정, 완료를 구분해요.
- 완료한 회귀 검사에서 수정 전에는 서버의 카드 보존 테스트와 프로젝트 필터의 표시 범위 테스트가 각각 `fail 1`이었어요. 수정 후 관련 테스트는 합계 `pass 18`, `fail 0`이에요.
- 완료한 타입 검사도 통과했고, 빌드 결과는 `✓ built in 1.19s`예요.
- 남은 일은 headless 검증(`spawnSync git EPERM`으로 미검증)과 PR 개설(현재 미개설) 및 머지예요.
