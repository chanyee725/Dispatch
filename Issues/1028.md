# #1028 E715: 단계 진행 표시와 ETA 기본값

- 서버: 새 단계에 들어갔는데 `eta_minutes`가 없으면 병합 확인된 끝난 task들의 같은 단계 소요 중앙값(최근 20번, 1분 미만 방문 제외)으로 `etaAt`을 채우고 `etaEstimated`로 표시. 기록이 없으면 비움. 관리자가 넣은 ETA가 아직 남아 있으면 그대로.
- 추정 ETA는 over-eta 멈춤 판정, 확인 필요(지연) 줄, agents-summary late에 넣지 않음. 관리자 보드 메모에는 `(예상)`.
- 웹: `StageProgress`(5칸 + `리뷰 · 3/5`)를 대시보드 이슈 줄과 세션 보드 작업 보드에 공통으로. 머지된 이슈는 기존 칩.
- 문구: `약 N분 남음(예상)`, 지나면 `N분 지남`; 작업 보드 카드는 `etaCardText`로 '예상'을 한 번만(`예상보다 N분 지남`).
- 팀 규칙·관리자 프롬프트: 단계를 바꿀 때마다 `eta_minutes`.
