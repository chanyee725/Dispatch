# #930 E680: 머지된 작업을 작업 보드에서 자동으로 완료 처리

- 서버가 1분마다(시작 직후 한 번) 열린 작업(plan~merge)을 확인해요: (a) commit이 develop에 있음 (b) 연결 PR merged (c) 연결 이슈 closed.
- 근거가 있으면 done으로 옮기고 `mergeCheck.via/evidence`에 남겨요. 없으면 그대로 두고 `autoCheck.reason`을 확인 필요 지연 줄에 붙여요.
- 닫힌 작업은 ETA·지연 경고를 지워요.
- 리뷰 반영: 새 커밋 없는 브랜치·계획/구현 단계의 해시는 근거가 아니에요. 근거 이슈는 작업 자신의 것(브랜치 번호, 제목 끝 #N)만, PR 번호와 이슈 번호는 섞지 않아요. 리드가 지워진 작업도 정리해요.
- 코드: server/dispatch/task-close.js, hub.js autoCloseTasks, index.js 타이머, issues.js allPrs/issueState.
- 확인: test/dispatch/task-close·issues·attention·git·module·stuck 테스트, npm run build(tsc 포함).
