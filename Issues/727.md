# #727 문서의 "에이전트 작업 중이에요" 영역에 에이전트가 많아도 들어가요

- 에이전트마다 한 줄(색 점·이름·상태)로 줄이고, 역할별로 묶어 개수를 보여요(관리자→디자이너→구현자→리뷰어→테스터→문서화 순).
- 접힌 상태에서는 최대 6줄을 역할마다 고르게 나눠 보이고, 나머지는 역할 아래 "+N명 더 보기"로 펼쳐요. "줄이기"는 머리에 있어 스크롤해도 보여요.
- 줄의 상태를 누르면 그 에이전트의 자세한 내용(모델, 지금 하는 일, 최근 단계)이 열려요. 혼자일 때는 늘 열려 있어요.
- 접힌 레일과 휴대폰 시트 막대의 점은 6개까지, 나머지는 +N으로 보여요. 높이는 화면(시트는 45%) 안에서 스크롤돼요.
- 그룹·오버플로 로직은 web/src/doc/marginGroups.ts(순수 함수)로 분리했어요.
