# #934 E681: 사이드바 너비 조절 + 긴 파일명 잘림 개선

- 사이드바 오른쪽 가장자리(role=separator)를 드래그, ←/→(Shift는 64px), Home, 더블클릭으로 200~480px 조절해요. 기본 264px.
- 너비는 localStorage `drawing:sidebar-width`에 기억해요(읽기·쓰기 try/catch). 좁은 화면 서랍은 264px 그대로예요.
- 문서 트리: 이름 칸이 남는 공간을 다 쓰고, 하위 문서 없는 줄은 ⋯ 자리만 비워요. 파이프라인 상태는 기호 하나, 글자는 툴팁.
- 잘린 이름과 문서 머리 제목 입력에 title 툴팁을 달았어요.
- 코드: web/src/lib/sidebarWidth.ts, components/ui/sidebar.tsx(SidebarResizeHandle), Sidebar.tsx, TopBar.tsx.
- 확인: test/web/sidebar-width.test.ts, tsc -p web, npm run build, 라이트/다크 200·264·480px 헤드리스 스크린샷.
