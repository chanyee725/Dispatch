# #1045 E715: 계획은 기획 폴더에, 시작하기 때 영역 폴더로 옮기기 + 짧은 제목

- write_plan: 경로 없는 새 계획은 `기획/<기능>/계획.dpx.json`에 써요. 목표 영역(area → 단계 files가 가장 많은 최상위 폴더 → 관리자 폴더)을 계획 항목에 남겨요. 동률이면 문서 첫 줄에 "기획 폴더에 그대로 있어요" 안내
- 시작하기: 실행 기록을 만들기 전에 기능 폴더째(하위 문서·다이어그램 포함) `<영역>/<기능>`으로 옮겨요. 이름이 있으면 `-2`, 이동 실패면 기획에 두고 시작, 관리자 전달 실패면 다시 기획으로, 동시에 두 번 누르면 하나만 시작, 같은 기능 폴더에 다른 계획이 있으면 폴더를 옮기지 않고 기획에 둠
- 이동은 기존 store.move를 써서 계획 상태·초안·실행 기록·기록 이력·세션 폴더가 새 경로를 따라가요. 열린 탭도 닫히지 않고 새 경로로 따라가요
- 제목: goal로 만드는 기본 제목은 20자(단어 경계)로 자르고, 20자 넘는 title·feature는 받되 warnings로 알려요
- 사이드바(트리) 최상위에서 `기획` 폴더가 맨 위예요
- 안내: atelier-plan·atelier-organize·atelier-doc·atelier-diagram 스킬, write_plan 도구 설명, 관리자 프롬프트
- 검사: pipeline-draft-move(새)·pipeline-plan·pause·reopen·follow·session-folder·lanes·plan-write·externalChange·workspace-files 테스트, tsc, npm run build, 헤드리스 전후 스크린샷
