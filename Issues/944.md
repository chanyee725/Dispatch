# E687: 타임라인 범위 30분 고정 + 5초 갱신 표시 (#944)

- 보이는 범위는 항상 최근 30분이에요. 30초·1분·5분은 집계 간격과 눈금만 바꿔요.
- 카드 부제: "최근 30분 · 30초 간격" 형태.
- 타임라인 아래 "최근 업데이트 …"를 5초마다 다시 계산해요. 갱신 때 점이 한 번 깜빡이고 막대가 300ms linear로 밀려요.
- 폴링 5초, 화면이 보일 때만(visibilitychange). 움직임 줄이기면 글자만 바뀌어요.
- 확인: test/web/dispatch-timeline.test.ts 통과, npm run build 통과, 헤드리스 라이트/다크 스크린샷.
